# Mjuma Online Stores

A simple, mobile-friendly website for Mjuma Online Stores in Mtwapa, Kenya.

## Features

- Product catalogue with search and category filters
- WhatsApp ordering links for every product
- M-Pesa payment details with copy button
- Contact and location details
- Responsive design for phones, tablets, and computers

## Publish on GitHub Pages

1. Upload or import this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch: `main`, folder: `/ (root)`.
5. Save. Your website will be available at:

`https://BAgwanda254.github.io/mjuma-online-stores/`

## Edit products

Open `index.html` and find the `products` array. Add, remove, or update products there.
